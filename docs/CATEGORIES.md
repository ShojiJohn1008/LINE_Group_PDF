# 分類体系（ナレッジベースの統制語彙）

総合診療科のナレッジベース用。**これは固定リスト（controlled vocabulary）**で、
AIの分類・Driveのフォルダ・ダッシュボードのフィルタの共通の背骨になる。コードの
実体は `src/categories.ts`（こちらが唯一の真実）。ここは人間向けの説明。

## 2軸で分類する

- **主題カテゴリ**（1資料に必ず1つ）… Driveフォルダ・主フィルタになる背骨。
- **資料タイプ**（1資料に1つ）… ガイドラインか論文か等の横断フィルタ。主題と独立。
- **タグ**（自由語・複数）… 上記の下の補助。増やしてよい。

## 運用ルール

- **主題は必ず1つ**。迷ったら「より臨床行動に近い方」、それでも迷えば
  「総合診療・診断推論（症候）」へ。判定不能なら「その他・未分類」。
- 多主題の資料（例：糖尿病×腎症）は主題1つ＋**タグで補足**（`#腎症` 等）。
- カテゴリ／タイプは**固定**（AIはこの中から選ぶ）。タグは自由。

## 変更するときは

`src/categories.ts` と このファイルを**両方**更新する（コードが真実、ここは説明）。
カテゴリ名はDriveフォルダ名・保存済みデータにも使われるため、**改名は慎重に**
（既存資料の再分類・フォルダ移動が必要になる）。
